# RulesForge Extension Examples

This directory contains extension examples, not basic C API usage.

Standard reusable extension uses the public vtable ABI in `../../include/rule_forge_plugin.h`.

Native function table examples are kept here because they are extension examples too, but they are only for RHS `invoke(...)` callbacks, not the general source/sink plugin ABI.

Files:

- `native_functions_demo.cpp`
- `native_table_plugin.cpp`
- `native_function_table_demo.cpp`

- `CAPI_NATIVE_DLL_ZH.md`

- `CAPI_NATIVE_DLL_QUICKSTART_ZH.md`
